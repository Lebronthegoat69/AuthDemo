# AuthDemo

## Project Description

AuthDemo is an ASP.NET Core Razor Pages application that demonstrates authentication and authorization using cookie-based authentication.

Users can log in with a username and password to access a protected Admin Dashboard. The application stores user information in a JSON file and uses password hashing to protect passwords.

## Features

- Cookie-based authentication
- Login and logout functionality
- Password hashing using ASP.NET Core Identity
- User information stored in `data/users.json`
- Protected Admin Dashboard using the `[Authorize]` attribute
- Automatic redirection to the Login page when an unauthorized user tries to access the Admin Dashboard
